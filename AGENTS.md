# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

Note: the project was intentionally downgraded from SDK 56 to SDK 54 in julho/2026, because Apple had not
yet approved the SDK 55/56 update for the public App Store version of Expo Go (see Expo's May 2026
changelog). SDK 54 is the version guaranteed to run in the regular App Store Expo Go app on a physical
iPhone with no TestFlight/dev-build workaround needed. Do not bump back to 56 without checking whether
that's still the case.
